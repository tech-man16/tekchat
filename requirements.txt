Login and user creation flow:
    1) Go to login page and enter a username and password to create a new user.
    2) After successful login, you will be redirected to the home page.
    3) If you try to login with the same username and password again, it will log you in successfully without creating a new user.
    4) If you try to login with a different username or password, it will create a new user and log you in successfully.
